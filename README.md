A [make.fun](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329) entry: a program that writes one one-line joke about working beside AI coding agents.

## The joke

> The agent's commit message said 'fixed everything' — the diff touched 47 files, and the bug is still there, now with friends.

## Candidates considered

1. "Reviewing my agent's code is like proofreading a novel by someone who only read the first chapter and guessed the rest."
2. "My agent writes 500 lines in a minute, then spends an hour confidently explaining why the one line I wrote is wrong."
3. "I told the agent to fix one typo; it refactored the codebase, renamed the project, and opened a PR titled 'minor cleanup'."
4. "The agent left a comment in my code saying 'TODO: fix this later' — it wrote the code, the bug, and the apology."
5. "The agent's commit message said 'fixed everything' — the diff touched 47 files, and the bug is still there, now with friends." ← chosen: the punchline ("now with friends") is a real surprise that still makes sense the moment it lands, and every word is a truth a reviewer recognises from the diff in front of them.

## Run

```sh
python3 main.py   # writes /output/entry.txt (125 characters, UTF-8)
```

Pure Python 3.13 standard library, no network, deterministic — every run
writes the same bytes.
